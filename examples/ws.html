WebSocket demo

Uses wss://echo.websocket.events — every message sent is echoed back.

Quick examples

Usage

The <ws-connect> component manages the WebSocket lifecycle. It auto-reconnects every 3 seconds on disconnect.

Basic

<ws-connect url="wss://echo.websocket.events"
  :on.message="handle($event)">
</ws-connect>

With send()

send() is a method on the component state. Call it from any :on.* handler:

<button :on.click="ws.send('hello')">Send</button>

Message event

The :on.message handler receives the raw MessageEvent. Access the data via $event.data:

:on.message="_.log += $event.data + '\n'"

JSON parsing

Parse incoming JSON inside the handler:

:on.message="_.data = JSON.parse($event.data)"

HTML injection

If the server sends HTML, inject it carefully:

:on.message="_.container.innerHTML = $event.data"
